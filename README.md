# Reload Split View Extension (分割ビュー連動リロード拡張機能)

Chromeのネイティブ機能「タブを分割ビューで開く（Split View）」に対応した、左右のタブを連動してリロードさせるためのManifest V3拡張機能です。

---

## 🎯 主な機能

1. **連動リロード:** 
   分割ビュー（同じ `splitViewId` を共有するペアタブ）の片方をリロードした際、もう片方のタブも自動的に連動してリロードします。
2. **無限ループ防止:** 
   連動リロードが連鎖して無限にリロードし合うのを防ぐため、拡張機能によるリロードイベントをセッションストレージ（`chrome.storage.session`）でフラグ管理し、安全に遮断します。
3. **修飾キーによるスキップ (片側リロード):** 
   特定の修飾キー（デフォルトでは **Shiftキー**）を押しながらリロード操作をした場合、連動リロードをスキップし、操作したタブのみを単一リロード（Chrome標準の挙動）します。
4. **キーボードテスター付き設定画面:** 
   どの修飾キー（Shift, Ctrl, Alt, Meta）で連動をスキップするか個別に設定できます。また、キー入力がブラウザ上で正しく認識されているかテストできるインジケーターが付いています。

---

## 🛠️ 導入手順 (インストール方法)

1. Chromeを開き、アドレスバーに `chrome://extensions/` と入力して拡張機能管理ページを開きます。
2. 画面右上の **「デベロッパー モード」** トグルスイッチをオンにします。
3. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
4. 本プロジェクトのディレクトリ（`reload-split-view-extension`）を選択して読み込みます。
5. ツールバーに拡張機能アイコン（🔄）をピン留めしておくと状態が確認しやすくなります。

---

## 💡 使い方

### 通常の連動リロード
1. Chromeでタブを右クリックし、**「タブを分割ビューで開く」** などを選択して2つのタブを分割表示します。
2. 片方のタブでリロード（`F5`、`Ctrl+R`、またはブラウザのリロードボタンをクリック）を実行します。
3. **左右両方のタブが連動してリロード**されます。

### 修飾キーによるスキップ（片方のみリロード）
1. 設定で有効にしている修飾キー（例: **Shiftキー**）を押したままにします。
2. その状態でリロードを実行します。
3. **操作したタブのみがリロードされ、もう片方のタブはリロードされません。**

## ⚙️ 各種設定

拡張機能アイコンをクリックし、ポップアップ内の **設定ボタン（⚙️）** または拡張機能管理ページの「詳細」＞「拡張機能のオプション」から設定画面を開くことができます。

* **機能の有効化:** 連動リロード全体のON/OFFを切り替えます。
* **スキップ用修飾キー:** 
  * `Shift キー`（推奨・デフォルト）
  * `Ctrl キー`
  * `Alt キー`
  * `Meta キー` (Windowsキー / Mac Commandキー)
* **キーボード動作テスト:** 
  設定ページ上でキーを押すと、拡張機能がそのキーを正しく検出できているかがリアルタイムで点灯します。うまく動作しない場合の切り分けにご利用ください。

---

## ⚠️ 注意事項・制限事項

* **ブラウザ要件:** 本機能は `splitViewId` APIを使用しているため、同APIをサポートする比較的新しいバージョンのChrome（Chrome 140以降）が必要です。
* **ブラウザUIクリック時の判定:** 
  ユーザーがブラウザ標準のリロードボタンを修飾キーを押しながらマウスでクリックする場合、一瞬Webページからフォーカスが外れる（`blur`）ため、キー判定が消えてしまう問題があります。本拡張機能では、フォーカス喪失後 **500ms** はキー状態を維持するディレイ処理を入れることでこの問題を回避しています。
